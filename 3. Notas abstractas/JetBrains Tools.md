###### Navegación y gestión de pestañas

- Fijar pestañas (**Click derecho**)
- Desplazarse en las pestañas de manera horizontal (**Scroll**)
- Copiar ruta de un archivo desde la pestaña (**Click derecho**)
- Cambiar rápidamente entre archivos abiertos (**Ctrl + Tab**)

- Buscar rápidamente una clase (**Ctrl + N**)
- Buscar código en todo el proyecto (**Ctrl + Mayús + F**)
- Mostrar una lista de opciones de acceso rápido (**Ctrl + E**)
- Buscar todas las referencias de una clase, método o variable en el proyecto (**Alt + F7**)
###### Edición y manipulación de código

- Duplicar una línea de código (**Ctrl + D**)
- Copiado inteligente (**Ctrl + W**)
- Refactorizar nombres rápidamente (**Mayús + F6**)
- Desplazamiento rápido de código (**Ctrl + Shift + Flechas**)
- Desplazamiento horizontal rápido en el código (**Ctrl + Flechas**)
- Formateo rápido (**Ctrl + Alt + L**)
- Buscar y reemplazar en múltiples archivos (**Ctrl + Shift + R**)
###### Asistencia y sugerencias

- Sugerencia de autocompletado básica (**Ctrl + Espacio**)
- Sugerencia de autocompletado con IA (**Ctrl + Mayús + Espacio**)
- Traducir la documentación (**Click derecho**)
###### Análisis de código

- Mostrar la jerarquía de herencia de una clase (**Ctrl + H**)
- Mostrar la jerarquía de llamadas para un método (**Ctrl + Alt + H**)
- Agregar como favorita una línea de código (**F11**)

## Descripción de UI para Local Network Manager

Create a modern web application dashboard for a home network management tool with the following specifications:

**Main Layout:**

- Clean, responsive design with a dark sidebar navigation and light main content area
- Top navigation bar with user profile, notifications, and settings icons
- Sidebar menu with icons for: Dashboard, Devices, Access Control, Network Monitor, and Settings

**Dashboard Page (Main View):**

- Header with "Network Overview" title and current network status indicator (green dot for "Connected")
- Top row with 4 stat cards showing: Total Devices (with number), Active Devices, Blocked Devices, and Network Speed
- Bottom section with two columns:
    - Left: "Recent Activity" list showing device connections/disconnections with timestamps
    - Right: "Bandwidth Usage" chart (donut or bar chart)

**Device Management Section:**

- Data table with columns: Device Name, IP Address, MAC Address, Status (Online/Offline), Device Type (with icons), Actions
- Search bar above the table with filters for device type and status
- "Add Device" button in top right

**Access Control Panel:**

- Toggle switches for each device with labels "Internet Access Enabled/Disabled"
- Schedule selector for time-based restrictions (weekly calendar grid)
- Quick action buttons: "Block All", "Allow All"

**Visual Style:**

- Modern, minimalist design with rounded corners
- Color scheme: Dark blue/navy sidebar, white/light gray main area, green for active/allowed, red for blocked/offline
- Use Material Design or similar modern UI components
- Responsive grid layout that works on desktop and tablet
- Icons should be clear and intuitive (use Lucide or Heroicons style)

**Interactive Elements:**

- Hover effects on cards and buttons
- Loading states for network scanning
- Real-time updates with smooth animations
- Toast notifications for actions (device blocked/unblocked)
- Modal dialogs for device details and settings

Create this as a React component with TypeScript, using modern CSS (flexbox/grid) and make it fully responsive.

###### Planteamientos metodológicos 

- ¿Es esta una historia técnica o de usuario?:
- ¿La historia es suficientemente clara, o se requiere agendar reuniones con el PO o el líder técnico?:
	- ¿La historia es más compleja de lo esperado?
- ¿La descripción de la historia requiere refinamiento?
- ¿Hay una mejor alternativa para dar solución al problema raíz?

###### Planteamientos técnicos generales: 

- ¿Sobre que áreas se debe incidir para llevar a cabo la historia?*
- Si la historia requiere una modificación en el frontend, ¿sobre que módulos o vistas se debe interferir?
- Si la historia requiere una modificación en el backend, ¿sobre que microservicio se debe interferir?
- Si la historia requiere una modificación en la base de datos ¿sobre que base de datos, tablas y columnas se debe interferir?
- ¿Cuál es la área inicializadora del problema? 
- ¿Qué permisos necesito para llevar a cabo esta historia?
- ¿A qué plataformas debo acceder para llevar a cabo esta historia?

**Planteamientos específicos:** 

- ¿Este carácter solo se permite en el primer nombre o también en otros campos?
- ¿Este carácter solo se permite en estos nombres específicos, o aplica para cualquier nombre?
- ¿Únicamente se debe permitir bajo las condiciones mencionadas,?

###### Concepto:

Un tipo de **dato no literal** es un [[1.6 Valor|valor]] que no se expresa como sí mismo, sino que se representa abstractamente como el [[1.6 Valor|valor]] de un elemento o el resultado de una [[1.5 Expresión|expresión]]. El valor de un dato no literal puede cambiar durante el tiempo de ejecución de un [[4. Programa|programa]].

###### Anotaciones:

> *"Los datos no literales son aquellos que no están codificados directamente en el código fuente, sino que se obtienen o calculan durante la ejecución del programa."*

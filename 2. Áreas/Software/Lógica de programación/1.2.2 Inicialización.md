###### Concepto:

La **inicialización** es el proceso mediante el cual, tras la [[1.2.1 Declaración|declaración]], se asigna por primera vez un [[1.6 Valor|valor]] concreto a la [[1.2 Variable|variable]], evitando así estados indefinidos o nulos.

###### Anotaciones:

>*En algunos lenguajes de programación si no se inicializan las variables, estas obtienen un valor por defecto.*

IP = Internet Protocol

Es la dirección para identificar una computadora o nodo conectado a internet
se compone de 4 grupos de número que van del 0 al 256 (byte) osea 8bits x4 bytes = 32 bits, las direcciones IP deben ser unicas, la organización IANA gestiona que direcciones IP permanentes se les asigna a las computadoras en el mundo###### Concepto:

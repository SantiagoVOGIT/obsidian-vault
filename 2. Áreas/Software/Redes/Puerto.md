###### Concepto:

Número que identifica una aplicación servicio especifico que esta corriendo en una computadora, e

existen puertos de salida (random o especifico en muy pocos casos) y puertos de entrada

la cantidad de puerto posibles es de 16 bits

| Rango           | Nombre                              | Uso típico                                                                                   |
| --------------- | ----------------------------------- | -------------------------------------------------------------------------------------------- |
| **0–1023**      | Puertos bien conocidos (well-known) | HTTP, FTP, SSH, etc. – asignados por IANA.                                                   |
| **1024–49151**  | Puertos registrados                 | Destinados para servicios conocidos pero no esenciales o aplicaciones del usuario            |
| **49152–65535** | Puertos dinámicos / privados        | Elegidos por el sistema operativo cuando inicia una conexión (no reservados. libres de uso). |


| Estado del puerto       | Descripción |
| ----------------------- | ----------- |
| Puerto abierto (Open)   |             |
| Puerto cerrado (Closed) |             |
| Puerto filtrado (FWL)   |             |

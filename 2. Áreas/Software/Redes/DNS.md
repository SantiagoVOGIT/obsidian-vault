###### Concepto:


es un estandar administrado por IANA

root servers

bases de datos gigantescas en donde se relacionan la dirección IP con el nombre del dominio, basicamente decir "este nombre corresponde a este servidor" estas bases de datos son clonadas por los IXP, ISP, e incluso de manera local en computadoras personales, cuando esta base de datos se actualiza se envia a una señal a todos las computadores para que actualicen su copia

Los DNS funcionan por cache, si el usuario no tiene la IP en su cache DNS local hace una consulta a su servidor DNS configurado y si ese servidor no la tiene hace una consulta a los root servers, de esta manera se ahorra tiempo y trafico



TLD (Top Level Domain) son administrados por NIC, GTLD ( Geographic Top Level Domain)

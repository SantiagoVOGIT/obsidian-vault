###### Concepto:

- [[Protocolo IP]]
- [[IPv4]]
- [[IPv6]]

|Protocolo|Nombre Completo|RFC Principal|Función Principal|
|---|---|---|---|
|**IPv4**|Internet Protocol version 4|RFC 791|Protocolo principal de enrutamiento y direccionamiento|
|**IPv6**|Internet Protocol version 6|RFC 8200|Protocolo de nueva generación con direcciones expandidas|
|**ICMP**|Internet Control Message Protocol|RFC 792|Mensajes de control y error para IPv4|
|**ICMPv6**|Internet Control Message Protocol for IPv6|RFC 4443|Mensajes de control y error para IPv6|
|**IGMP**|Internet Group Management Protocol|RFC 3376|Gestión de grupos multicast para IPv4|
|**MLD**|Multicast Listener Discovery|RFC 3810|Gestión de grupos multicast para IPv6|
|**ARP**|Address Resolution Protocol|RFC 826|Resolución de direcciones IP a MAC (IPv4)|
|**NDP**|Neighbor Discovery Protocol|RFC 4861|Descubrimiento de vecinos para IPv6 (reemplaza ARP)|
|**IPSec**|Internet Protocol Security|RFC 4301|Seguridad y cifrado a nivel de IP|

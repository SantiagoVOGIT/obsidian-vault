###### Concepto:

- [[UDP]]
- [[TCP]]

| Protocolo | Características                                         | Casos de Uso                                                                                                                                                                                                                                                                 |
| --------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TCP**   | Orientado a conexión, fiable, full‑dúplex, resiliente   | Protocolos web (HTTP/HTTPS), servicios de email, transferencia de archivos, acceso remoto                                                                                                                                                                                    |
| **UDP**   | Sin conexión, no fiable, baja latencia                  | Servicios DNS, streaming multimedia, aplicaciones de tiempo real, protocolos de red, VoIP                                                                                                                                                                                    |
| **SCTP**  | Orientado a mensaje, fiable, multistream, multihoming   | Señalización telefónica, aplicaciones VoIP, sistemas de telecomunicaciones, transporte confiable                                                                                                                                                                             |
| **QUIC**  | Basado en UDP, TLS integrado, multiplexación, migración | Comunicaciones web seguras, aplicaciones con migración de red, transporte multiplexado de baja latencia [HAProxy](https://www.haproxy.com/blog/choosing-the-right-transport-protocol-tcp-vs-udp-vs-quic)[Auvik](https://www.auvik.com/franklyit/blog/what-is-quic-protocol/) |

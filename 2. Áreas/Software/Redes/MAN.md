###### Concepto:

Una red **MAN** abarca una ciudad o área metropolitana completa, conectando múltiples [[LAN|LANs]] distribuidas en diferentes ubicaciones urbanas. Esta red proporciona conectividad de alta velocidad entre oficinas corporativas, instituciones gubernamentales y centros de datos dentro de la misma región metropolitana. Las tecnologías empleadas incluyen fibra óptica, microondas y conexiones de banda ancha dedicadas.

|Tecnología|Cobertura típica|Velocidad máxima|Tipo de enlace físico|Caso de uso típico|
|---|---|---|---|---|
|Metro Ethernet|2-100 km|10-400 Gbps|Fibra óptica monomodo|Interconexión campus, ISP metropolitano|
|Microondas E-Band|1-15 km|1-10 Gbps|Inalámbrico (71-76/81-86 GHz)|Backhaul celular, backup fibra, sitios remotos|
|5G mmWave Fixed|200 m-2 km|1-10 Gbps|Inalámbrico (24-39 GHz)|Internet residencial/empresarial, last-mile|
|SONET/SDH|2-160 km|40-100 Gbps|Fibra óptica monomodo|Redes telecom, enlaces troncales, sincronización|

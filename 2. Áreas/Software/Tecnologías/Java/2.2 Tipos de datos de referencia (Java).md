###### Concepto:

Los **tipos de referencia** almacenan enlaces a objetos o estructuras dinámicas y permiten manipular instancias de clases, colecciones, etc. Según la especificación de **Java SE**, existen cuatro clases principales de tipos de referencia [Oracle Docs](https://docs.oracle.com/javase/specs/jls/se12/html/jls-4.html):

- **Tipos de clase**  
    Cualquier clase definida por el usuario o del API de Java (por ejemplo, `String`, `Integer`, clases envoltura).
    
- **Tipos de interfaz**  
    Referencias a instancias de clases que implementan una interfaz (por ejemplo, `List`, `Runnable`).
    
- **Variables de tipo (genéricos)**  
    Parámetros de tipo en clases o métodos genéricos (por ejemplo, `T` en `List<T>`).
    
- **Tipos de arreglo**  
    Secuencias indexadas de elementos, p. ej. `int[]`, `String[]`.

###### Concepto:

**Java** cuenta los siguientes [[1.8.2 Operadores de asignación|operadores de asignación]]:

| Operador | Descripción                                    | Ejemplo               |
| -------- | ---------------------------------------------- | --------------------- |
| `=`      | Asignación simple                              | `a = b`               |
| `+=`     | Suma y asigna                                  | `a += b`              |
| `-=`     | Resta y asigna                                 | `a -= b`              |
| `*=`     | Multiplica y asigna                            | `a *= b`              |
| `/=`     | Divide y asigna                                | `a /= b`              |
| `%=`     | Módulo y asigna                                | `a %= b`              |
| `&=`     | AND bit a bit y asigna                         | `a &= b`              |
| `^=`     | XOR bit a bit y asigna                         | `a ^= b`              |
| `<<=`    | Desplazamiento a la izquierda y asigna         | `a <<= b`             |
| `>>=`    | Desplazamiento a la derecha y asigna           | `a >>= b`             |
| `>>>`    | Desplazamiento a la derecha sin signo y asigna | `a >>>= b`            |

###### Concepto:

**Java** cuenta los siguientes [[1.8.1 Operadores aritméticos|operadores aritméticos]]:

| Operador | Descripción     | Ejemplo       |
| -------- | --------------- | ------------- |
| `+`      | Suma            | `a + b`       |
| `-`      | Resta           | `a - b`       |
| `*`      | Multiplicación  | `a * b`       |
| `/`      | División        | `a / b`       |
| `%`      | Módulo (resto)  | `a % b`       |
| `++`     | Incremento en 1 | `++a` o `a++` |
| `--`     | Decremento en 1 | `--a` o `a--` |

###### Anotaciones:

> *En los lenguajes derivados de C, las operaciones con enteros devuelven como resultado un valor entero*

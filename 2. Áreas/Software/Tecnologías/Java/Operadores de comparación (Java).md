###### Concepto:

Java cuenta con los siguientes [[1.8.3 Operadores de comparación|operadores de comparación]]

|Operador|Descripción|Ejemplo|
|---|---|---|
|`==`|Igual a|`a == b`|
|`!=`|Diferente de|`a != b`|
|`>`|Mayor que|`a > b`|
|`<`|Menor que|`a < b`|
|`>=`|Mayor o igual que|`a >= b`|
|`<=`|Menor o igual que|`a <= b`|
|`instanceof`|Verifica si un objeto es instancia de una clase|`obj instanceof Clase`|

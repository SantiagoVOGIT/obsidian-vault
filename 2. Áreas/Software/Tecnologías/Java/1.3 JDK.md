El **JDK** (Java Development Kit) es el **SDK** perteneciente a Java, y proporciona un entorno de desarrollo para construir aplicaciones y componentes en Java. Así mismo, incluye una amplia gama de herramientas y utilidades para el desarrollo de aplicaciones en el lenguaje.

###### Anotaciones:

> Básicamente, el JDK es un paquete completo que proporciona todos los componentes necesarios para desarrollar, compilar, depurar y ejecutar aplicaciones escritas en Java. Es esencial para cualquier desarrollador de Java.

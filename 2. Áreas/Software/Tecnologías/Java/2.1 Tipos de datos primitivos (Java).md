 ###### Concepto:

Los **tipos primitivos** están predefinidos de manera nativa en el lenguaje y se identifican por palabras clave reservadas. **Java** dispone de ocho tipos primitivos [Oracle Docs](https://docs.oracle.com/javase/specs/jls/se12/html/jls-4.html):

|Tipo|Tamaño|Descripción|Valor por defecto|
|---|---|---|---|
|`byte`|8 bits|Entero con signo de 8 bits (–128 a 127)|`0`|
|`short`|16 bits|Entero con signo de 16 bits (–32 768 a 32 767)|`0`|
|`int`|32 bits|Entero con signo de 32 bits (–2 147 483 648 a 2 147 483 647)|`0`|
|`long`|64 bits|Entero con signo de 64 bits (–9×10^18 a 9×10^18)|`0L`|
|`float`|32 bits|Punto flotante de simple precisión IEEE 754|`0.0f`|
|`double`|64 bits|Punto flotante de doble precisión IEEE 754|`0.0d`|
|`char`|16 bits|Carácter Unicode (0 a 65 535)|`'\u0000'`|
|`boolean`|1 bit (lógico)|Valores lógicos `true`/`false`|`false`|

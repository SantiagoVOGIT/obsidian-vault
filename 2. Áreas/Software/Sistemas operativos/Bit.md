###### Concepto:
Binary Digit

El sistema binario se basa en un concepto matemático de potencias de 2 en orden descendente
$2^7, 2^6, 2^5, 2^4, 2^3, 2^2, 2^1, 2^0.$
En el contexto binario: **Valores posicionales en base 2 o **Pesos binarios**


| Bits    | Bytes   | Posibles valores       |
| ------- | ------- | ---------------------- |
| 8 bits  | 1 byte  | $2^8=256$              |
| 16 bits | 2 bytes | $2^{16}=65,536$        |
| 32 bits | 4 bytes | $2^{32}=4,294,967,296$ |

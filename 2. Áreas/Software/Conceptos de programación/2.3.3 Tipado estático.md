###### Concepto:

Un lenguaje de **tipado estático** asocia y comprueba los [[1.7 Tipos de datos|tipos]] de [[1.2 Variable|variables]] en tiempo de compilación. Una vez [[1.2.1 Declaración|declarado]] o inferido, el tipo no puede cambiar en ejecución (runtime).

**Características clave:**

- El compilador conoce el tipo de cada [[1.2 Variable|variable]] antes de ejecutar.
- Puede ofrecer _type inference_, deduciendo tipos sin anotaciones explícitas.
- Errores de tipo se detectan antes de correr el programa.

###### Anotaciones:

> El elemento esta sujeto a un tipo de dato, mas no su [[1.6 Valor|valor]], el cual si puede ir fluctuando o cambiando durante el flujo del programa

###### Concepto:

Para que un lenguaje de programación pueda ser comprendido por un ordenador, este debe de pasar por un proceso de **traducción** a [[Lenguaje máquina|lenguaje máquina]], que es el lenguaje mediante el cual puede iterar el hardware.

###### Concepto:

En **JSON** existen los siguientes [[1.7 Tipos de datos|tipos de datos]] para un [[1.6 Valor|valor]]:

- **Objeto**: Es una colección no ordenada de pares clave/valor Comienza con { (llave de apertura) y termina con } (llave de cierre). Cada nombre es seguido por : (dos puntos) y los pares nombre/valor están separados por , (coma). **Ejemplo:**

```
{
  "nombre": "Juan",
  "edad": 30,
  "ciudad": "Madrid"
}
```

- **Array**: Es una colección ordenada de valores, dichos valores pueden ser otros tipos de datos de JSON, incluso un array puede contener otro array. Comienzan con [ (corchete de apertura) y termina con ] (corchete de cierre). Los valores se separan por , (coma). **Ejemplo**:

```
["manzana", "banana", "cereza"]
```

- **Número**: Explicación: Es un valor numérico sin comillas. Puede ser un [[1.11.1.1 Números enteros|número entero]], un [[1.11.1.2 Números reales|número real]], o hasta una notación científica. **Ejemplo**:

```
42
3.14
-1.5e+2
```

- **Cadena (String)**: Es una secuencia de cero o más caracteres Unicode, envueltos en comillas dobles. Utiliza escape de barra invertida para caracteres especiales. **Ejemplo**:

```
"Hola, mundo!"
```

- **Booleanos**: Representa un valor de verdad. Puede ser true o false, sin comillas. **Ejemplo**:

```
true
false
```

- **Null**: Representa un valor nulo o vacío. **Ejemplo:**

```
null
```

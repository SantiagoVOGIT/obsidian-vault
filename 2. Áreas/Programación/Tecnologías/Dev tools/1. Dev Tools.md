###### Concepto:

Son herramientas que proporcionan los navegadores con el fin de facilitarlo a los desarrolladores la depuración del flujo de sitios web. Se conforma por varias secciones clave:

 - **Elements**:
	- Nos permite visualizar y manipular el código HTML y CSS 
- **Console:**
	- Nos permite ejecutar código JavaScript así como la depuración del mismo
- **Sources:**
	- Nos permite visualizar el código fuente por dominio
- **Network:**
	- Nos permite visualizar todas las peticiones que esta realizando el navegador a servidores remotos
- Application:
	- Nos permite visualizar todo lo que este guardando el sitio web en nuestro navegador

###### Concepto:

El **JRE** (Java Runtime Environment) es el entorno de ejecución de Java, y proporciona las bibliotecas y componentes necesarios para ejecutar aplicaciones escritas en el lenguaje Java. A diferencia del **JDK**, el JRE no incluye herramientas de desarrollo, sino únicamente las necesarias para ejecutar programas ya compilados. Es ideal para los usuarios que solo necesitan ejecutar aplicaciones Java, sin desarrollarlas.

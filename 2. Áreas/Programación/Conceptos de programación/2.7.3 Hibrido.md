###### Concepto:

Un lenguaje **mixto** o **híbrido** es un tipo de lenguaje de programación que combina características de los lenguajes [[2.7.1 Compilado|compilados]] e [[2.7.2 Interpretado|interpretados]].

En estos lenguajes, el [[3. Código fuente|código fuente]] se traduce primero a un **código intermedio** por un programa especial llamado compilador. Este código intermedio luego es ejecutado por una [[Maquina virtual|máquina virtual]], la cual puede:

1. Interpretar directamente el código intermedio, o
2. Compilarlo **just-in-time** (JIT) a [[Lenguaje máquina|lenguaje máquina]] para partes críticas o frecuentemente ejecutadas del programa.

La máquina virtual ejecuta el programa dentro de un entorno simulado, interactuando con el [[1. Sistemas operativos|sistema operativo]] y el hardware cuando es necesario. Este proceso proporciona un balance entre [[2.9 Portabilidad|portabilidad]], [[2.10 Rendimiento intrínseco|rendimiento]] y flexibilidad.

###### Características:

- Combina pasos de compilación e interpretación.

- Todo el código fuente se compila a un código intermedio.

- El código intermedio es interpretado o compilado just-in-time durante la ejecución.

- Los errores de [[2.1 Sintaxis|sintaxis]] se detectan durante la compilación inicial, pero pueden ocurrir errores en tiempo de ejecución.

- Alta portabilidad debido a que el código intermedio puede ejecutarse en cualquier plataforma que tenga la máquina virtual adecuada.

- Requiere la presencia del código intermedio y la máquina virtual para la ejecución.

- Permite cierto nivel de optimización en tiempo de ejecución.

- Combina ventajas de la compilación (como la detección temprana de errores) con la flexibilidad de la interpretación.

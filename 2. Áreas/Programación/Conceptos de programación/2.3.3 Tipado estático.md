###### Concepto:

Un lenguaje de **tipado estático** es aquel en el que no se permite hacer una conversión o una [[1.2.3 Asignación|reasignación]] del [[1.7 Tipos de datos|tipo de dato]] con que fue [[1.2.1 Declaración|declarado]] un elemento. 

###### Anotaciones:

> Algunos lenguajes de tipado estático proporcionar el [[6.5 Casteo|casting]] para transformar de manera puntual el tipo de dato de un elemento

> El elemento esta sujeto a un tipo de dato, mas no su [[1.6 Valor|valor]], el cual si puede ir fluctuando o cambiando durante el flujo del programa

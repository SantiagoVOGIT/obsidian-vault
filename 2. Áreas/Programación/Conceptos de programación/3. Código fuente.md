###### Concepto:

El **código fuente** es el texto original mediante el cual fue construido un software. Es aquel conjunto de líneas de código que contienen las expresiones explicitas que dictan el funcionamiento de un [[4. Programa|programa]] informático. 

###### Anotaciones:

> Es la forma original y editable del software antes de ser compilado o interpretado para su ejecución.

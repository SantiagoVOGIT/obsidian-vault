###### Concepto:

Un tipo de **dato literal** es un [[1.6 Valor|valor]] fijo que se expresa como sí mismo en lugar de como el valor de un elemento o el resultado de una [[1.5 Expresión|expresión]]. El valor de de un dato literal no puede cambiar durante el tiempo de ejecución de un [[4. Programa|programa]]. 

###### Tipos de datos literales: 

- [[1.11.1.1 Números enteros|Números enteros]]
- [[1.11.1.2 Números reales|Números reales]]
- [[1.11.1.4 Carácter|Carácter]]
- [[1.11.1.5 Cadena de caracteres|Cadena de caracteres]]
- [[1.11.1.6 Booleano|Booleano]]

###### Anotaciones:

> *"Un literal hace referencia a un valor que aparece en un programa y no se puede cambiar. Cada literal tiene un valor y un tipo de datos. El valor de cualquier literal no cambia mientras se ejecuta el programa y debe estar en el rango de valores representables para su tipo."*

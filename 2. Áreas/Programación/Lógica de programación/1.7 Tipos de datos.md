###### Concepto:

Los **tipos de datos** se pueden definir como un atributo que especifica qué clase de información puede contener un elemento. 

###### Índice:

- [[1.7.1 Datos literales]]
- [[1.7.2 Datos no literales]]

###### Anotaciones:

> *"En informática, los tipos de datos se refieren a las diferentes categorías o clases de información que se pueden almacenar y procesar en un programa de computadora. Estos tipos de datos proporcionan una forma de clasificar y organizar la información, lo que permite que los programas procesen y manipulen la información de manera efectiva."*

###### Concepto:

Los **operadores aritméticos** permiten realizar operaciones muy básicas de carácter matemático sobre los [[1.6 Valor|valores]] de los elementos. No obstante, el valor debe de haber sido instanciado de un [[1.7 Tipos de datos|tipo de dato]] compatible con dichos operadores.

###### Tipos de operadores aritméticos: 

| Operador | Descripción                        |
| -------- | ---------------------------------- |
| `+`      | Suma                               |
| `-`      | Resta                              |
| `*`      | Multiplicación                     |
| `/`      | División                           |
| `%`      | Módulo (resto de la división)      |
| `++`     | Incremento (pre y post incremento) |
| `--`     | Decremento (pre y post decremento) |

###### Anotaciones:

> Estos operadores solo permiten iterar [[1.11.1.1 Números enteros|números enteros]] y [[n]]

###### Concepto:

La **asignación** de una [[1.2 Variable|variable]] es la etapa posterior a la [[1.2.2 Inicialización|inicialización]], en esta etapa se puede modificar o [[Mutabilidad|mutar]] el [[1.6 Valor|valor]] con el que fue inicializada una variable. Este proceso puede ocurrir una cantidad indeterminada de veces en el tiempo de vida de una variable.

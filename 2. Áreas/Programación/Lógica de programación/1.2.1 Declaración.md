###### Concepto:

La **declaración** de una [[1.2 Variable|variable]] se refiere al proceso inicial de definir una variable dentro de un [[4. Programa|programa]]. En el proceso de declaración primordialmente se definen los atributos de la variable y un nombre único que permita identificarla. Este proceso solo puede ocurrir una vez en el tiempo de vida de una variable

###### Anotaciones:

> *"Desde una perspectiva técnica, la declaración de una variable implica informar al compilador o intérprete sobre el nombre de la variable y el tipo de datos que almacenará, reservando así el espacio de memoria adecuado."*
